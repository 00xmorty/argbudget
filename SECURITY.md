# Security

Supported version: 0.1.x. This tool reads sensitive local environment data in
memory but must never emit values or argument contents. Use --hide-names when
sharing reports, then manually review even aggregate counts.

Do not submit real secrets, private environment dumps or logs to public issues.
Report a vulnerability with a synthetic reproduction using GitHub's private
vulnerability reporting feature if available; otherwise open a minimal issue
asking for a private channel without disclosing exploit details or secrets.

Never run downloaded code before reviewing it. This program needs no root,
network access, telemetry, repair privileges or target execution.
